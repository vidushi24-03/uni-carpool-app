# Uni Carpool App

A Flask + SQLite web app that lets university students post long distance trips (e.g. travelling home) and lets other students book a seat, splitting the cost.

## Features
-  Post a trip with departure/destination, date, seats, and price per seat
-  View all currently posted trips
-  Book a seat on a trip (seats update in real time)

## Tech Stack
-  Python, Flask
-  SQLite

## Running locally
1. 'python3 -m venv venv'
2. 'source venv/bin/activate' (Mac/Linux) or 'venv\Scripts\activate' (Windows)
3. 'pip install -r requirements.txt'
4. 'python3 app.py'
5. Visit 'http://127.0.0.1:5000'
