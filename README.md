# Uni Carpool App

A Flask + SQLite web app that lets university students post long distance trips (e.g. travelling home) and lets other students book a seat, splitting the cost.

## Features
-  Post a trip with departure/destination, date, seats, and price per seat
-  View all currently posted trips
-  Book a seat on a trip (seats update in real time)

## Tech Stack

-  SQLite

## Running locally
1. Clone the repository:
'git clone https://github.com/vidushi24-03/uni-carpool-app.git'
'cd uni-carpool-app'
2. Create and activate a virtual environment:
'python3 -m venv venv'
'source venv/bin/activate' (Mac/Linux) or 'venv\Scripts\activate' (Windows)
3. Install dependencies:
'pip install -r requirements.txt'
4. Run the app: 
'python3 app.py'
5. Open your browser and go to 'http://127.0.0.1:5000'
